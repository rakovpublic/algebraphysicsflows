# Implementation status

Checkpoint: 2026-09-24. This is a scoped implementation and initial survey of the supplied [specification](UNIVERSAL_MATHEMATICS_SPEC.md), not completion of universal mathematics.

## Native execution delivered

ConcreteMathematics installs **840 operations from 44 algebra builders** in the original MathTool. Builders are in algebra/concrete; operation implementations are in operations/simple and operations/flat. Unit, rational integration bounds, polynomial iteration inputs, integer relation/category label pairs, tensor axis pairs and finite-function boundary pairs are additional supporting carriers.

Delivered families: Boolean, N, Z, Q, Q(i), rational Hamilton quaternions, prime fields, rational vectors/square matrices, variable-dimension vector and rectangular matrix families, affine solution sets, Q[x], Q(x), multivariate Poly(Q), PolynomialMap(Q), polynomial differential forms/cells/chains, S3, finite integer sets/relations/functions, rational samples and finite exact probability measures and Markov kernels on integers. Operations include exact arithmetic, embeddings, scalar actions in both orders, dot products, determinant/rank/inverse, characteristic/minimal polynomials, matrix polynomial evaluation, rational eigenvalues/eigenspaces/diagonalization, RREF and bases for nullspaces/row spaces/column spaces, exact affine parametrizations of rectangular linear systems, derivatives/integrals, multivariate partials/gradients/Hessians, polynomial-map composition/Jacobians/divergence/curl, polynomial-form wedge/exterior derivatives/pullbacks/insertion/Lie derivatives, oriented cubical boundaries/products/pushforwards and exact polynomial chain integration, finite-set operations, moments/covariances and conditioning, kernel composition, distribution evolution, stationary classes/laws, time reversal, hitting probabilities and finite mean hitting times. Finite simplicial complexes now compute integral homology with torsion and rational Betti numbers; canonical finitely generated abelian-group types provide direct sum, tensor, Hom, Tor_1 and Ext^1 over Z. Integer vectors/matrices add Smith decompositions with unimodular witnesses, integral kernel/image bases, cokernel presentations and Diophantine solution parametrizations; simplicial boundary matrices connect to these carriers. Retained abelian presentations now support quotient elements, projection/lifting, additive arithmetic, finite element orders and enumeration, and finite integer-scaling fibers. Explicit homomorphisms provide kernels, images, cokernels and their maps. Constructive integral homology now returns cycle bases, quotient presentations, representatives, bounding chains and maps induced by supplied degree matrices.

Scalar and flat unary execution are connected to Algebra, IAlgebraItem and AlgebraFlow. A x B -> A uses ICustomMemberOperation; A x B -> B uses ILeftProjectionOperation and returns the second carrier's IAlgebraItem wrapper. Flat transfer returns a list. Overloads select by the second operand class; result-algebra checks precede flow mutation.

## Verification

The Java suite has **317 tests**, including independent expected results for every native registration, partial-operation boundaries, serialization and repeated local-flow collection. A differential test checks **104 cases** generated independently with Python Fraction arithmetic and a permutation-expansion determinant. The suite also checks all 64 four-vertex undirected graphs and all 512 three-vertex directed graphs against independent invariants/reachability, all three-point endomaps, all unital three-arrow multiplication tables and adjoint constructions for all monotone maps between chains of size zero through four. Cone/cocone tests verify products, coproducts, equalizers, coequalizers, empty diagrams, unique factorizations and resource-exhaustion distinctions. Rectangular tests check all 729 matrices of shape 2 by 3 over {-1,0,1}, each with nine right-hand sides, against an independent minor-based rank oracle and direct substitution. Further tests check the four Moore-Penrose equations, projectors, least-squares orthogonality and minimum-norm identities for those 729 matrices and their transposes. Tensor product/contraction is compared with independent coordinate sums for all 6,561 pairs of ternary 2 by 2 matrices. Exterior tests additionally check independent wedge signs, Hodge/insertion identities, 729 ternary cross products and 512 binary 3 by 3 determinants. Quaternion tests compare 6,561 products with an independent basis table and check exact rotations and matrix round-trips for 624 small nonzero quaternions. Multivariate tests check all 729 ternary bivariate quadratics against exact centered-difference identities, plus rectangular chain rules, mixed partials, exact Taylor restrictions, vector-calculus identities and serialized gradient/Jacobian flows. Polynomial-form tests cover graded identities, nonlinear contravariant composition, independent minors for 729 ternary rectangular pullbacks, one exact oriented Stokes rectangle, aggregate resource limits and serialized curl flows. Chain tests add independent tensor-Simpson checks for 729 polynomials, exact signed integrals for 729 linear cells, nonlinear Stokes tests in dimensions one through four, graded product boundaries, negative-degree zero chains, pushforward/pullback compatibility and shared computation limits. Spectral tests check 512 binary 3 by 3 matrices against independent characteristic-polynomial determinants and minimality ranks, 81 ternary 2 by 2 spectra against the quadratic formula, and 624 small nonzero polynomials for rational roots/multiplicities; defective and nonrational spectra, companion matrices, exact similarities and serialized flows are also covered. Markov tests check 25 two-state chains against closed forms, 64 three-state chains against independent weighted paths, all 27 deterministic three-state cycle laws, and all 343 admissible three-state support graphs against graph search and directed spanning-tree stationary weights, plus gambler's ruin and serialized probability flows. Integral homology tests compare Smith factors with independent determinantal divisors for 625 integer 2 by 2 and 512 binary 3 by 3 matrices, and cover spheres, a torus, the projective plane, cyclic Moore-space torsion orders 3 through 10, suspensions and disconnected complexes. Abelian-group tests compare 144 cyclic direct sums with independent element-order histograms and finite Hom groups with enumerated maps, plus tensor/Tor/Ext identities, resource failures and serialized native flows. Integer-linear tests verify Smith witnesses for all 729 ternary 2 by 3 matrices and their transposes, compare 6,561 systems with independent determinantal-divisor lattice tests, and check inverses for 625 small square matrices. Empty shapes, full integer kernel lattices, image indices, boundary composition, exact conversions and serialized solver flows are covered. Presented-group tests compare 15,625 projected vectors with independent lattice-minor criteria, enumerate 64 small cyclic products against independent element-order counts, and compare scaling fibers for scalars -6 through 6 with exhaustive finite search. They also check free coordinates, presentation compatibility, original versus Smith generators, projection/lift round-trips, output limits and serialized native flows. Homomorphism tests compare all maps between cyclic groups of orders one through eight with independent modular arithmetic, check product maps against finite enumeration, and verify kernel/image/cokernel maps, free and mixed groups, original-coordinate matrix lifts, inverses across different presentations, empty shapes, native wrappers and serialized flows. Constructive homology tests compare 336 small chain complexes with independent primitive-lattice arithmetic and all 64 four-vertex graphs with independent connectivity, verify an order-two projective-plane cycle and its integral filling, and check circle reflection, disk inclusion, induced-map composition, boundary preservation, empty shapes, resource failures and serialized flows. Rational law samples and exhaustive finite arithmetic are empirical evidence, not general formal proofs.

Python checks validate source/test paths, required fields, evidence claims, extension links, requested topic inventory and manifest agreement. Reports must be fresh. [Maintenance instructions](ADDING_MATHEMATICS.md) list commands.

The initial registry has 1291 scoped records, covering all 322 distinct requested bullet concepts in specification sections 10-30, 62 domain descriptors and nine extension proposals. These are survey counts, not a percentage of all mathematics. All records remain human-unreviewed and formally unverified.

## Compatibility and limits

The user-requested ILeftProjectionOperation and flat signature changes return the second type's wrapper. ITransferFlatOperation's scalar return is corrected to a list. Implementers of those interfaces must recompile/adopt the contracts. Custom-member semantics are preserved.

Flows are finite/local. Names/raw classes are not dependent-domain proofs. Callback purity/termination are unchecked. Fixed Matn(Q).solve requires a nonsingular matrix; Affine(Q).solve handles consistent singular and rectangular systems and represents inconsistent systems as empty solution sets. The rational matrix carrier requires positive dimensions; the integer matrix carrier retains zero-sized shapes. No CAS service, proof checker, general real equality procedure, PDE solver or distributed-runtime certification is supplied.

The baseline Log4j API/core mismatch still emits a fallback logger diagnostic; it does not fail the tests.
